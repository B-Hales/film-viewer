# Film Viewer

View ColorPrint RIP `.prt` films and Illustrator host-separated `.ps` files in the browser — composite on a shirt color or one plate at a time. Files are decoded locally in the browser; nothing is uploaded.

Hosted at https://b-hales.github.io/film-viewer/ (Chrome/Edge needed for the design search).

Source of truth: `_MASTER WORKFLOW_/Script Folders/Film Viewer/Film Viewer.html` in the Lone Rock Scripting repo — copy it here as `index.html` to publish.
